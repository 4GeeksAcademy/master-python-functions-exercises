## One-click installation (recommended)

Open in [Codespaces](https://codespaces.new/?repo=4GeeksAcademy/master-python-functions-exercises) (recommended) or [Gitpod](https://gitpod.io#https://github.com/4GeeksAcademy/master-python-functions-exercises).

> Once VS Code is open, LearnPack should start automatically. If it doesn't, run `learnpack start` in the terminal.

## Local installation

1. Make sure you have [Node.js](https://nodejs.org) 18+ and [Python](https://www.python.org) 3.10+ installed.

2. Install LearnPack, the Python plugin and the testing tools:

```bash
npm i @learnpack/learnpack -g && learnpack plugins:install @learnpack/python
pip3 install pytest==6.2.5 pytest-testdox mock
```

3. Clone this repository and start the exercises:

```bash
git clone https://github.com/4GeeksAcademy/master-python-functions-exercises.git
cd master-python-functions-exercises
learnpack start
```

## What will you practice?

- **Exercises:** `001-026`
- **Focus:** defining functions, parameters, `return` (including several values), arithmetic operators, integer division and modulo, the `math` module, rounding, conditionals and simple loops
- **Difficulty:** beginner

## How are the exercises organized?

Each exercise folder contains:

1. `README.md` / `README.es.md`: the instructions (English / Spanish).
2. `app.py`: the starter file where you write your solution.
3. `test.py`: the automatic grading tests. You don't need to open it, but you can read it if you are stuck.

Click **Run** to execute your `app.py` and **Test** to grade it.
