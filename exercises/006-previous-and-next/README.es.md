# `006` Anterior y siguiente

Una función de Python puede retornar más de un valor a la vez: `return a, b` retorna una **tupla** `(a, b)`.

## 📝 Instrucciones:

1. Completa la función `previous_next(number)`.

2. **Retorna** el entero anterior y el siguiente, en ese orden.

## 📎 Ejemplo:

```py
print(previous_next(179))  # (178, 180)
print(previous_next(0))  # (-1, 1)
```

## 💡 Pista:

+ `return a, b` es lo mismo que `return (a, b)`.
