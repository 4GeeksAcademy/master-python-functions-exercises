# `006` Previous and Next

A Python function can return more than one value at once: `return a, b` returns a **tuple** `(a, b)`.

## 📝 Instructions:

1. Complete the function `previous_next(number)`.

2. **Return** the previous and the next integer, in that order.

## 📎 Example:

```py
print(previous_next(179))  # (178, 180)
print(previous_next(0))  # (-1, 1)
```

## 💡 Hint:

+ `return a, b` is the same as `return (a, b)`.
