# `004` Área de un triángulo rectángulo

El área de un triángulo rectángulo es la mitad de la base multiplicada por la altura: `area = base * height / 2`.

## 📝 Instrucciones:

1. Completa la función `area_of_triangle(base, height)`.

2. **Retorna** el área del triángulo.

## 📎 Ejemplo:

```py
print(area_of_triangle(3, 5))  # 7.5
print(area_of_triangle(4, 2))  # 4.0
```

## 💡 Pista:

+ El operador `/` siempre retorna un `float`, aunque el resultado sea un número entero.
