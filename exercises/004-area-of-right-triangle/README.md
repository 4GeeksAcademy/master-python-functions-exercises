# `004` Area of a Right Triangle

The area of a right triangle is half of the base multiplied by the height: `area = base * height / 2`.

## 📝 Instructions:

1. Complete the function `area_of_triangle(base, height)`.

2. **Return** the area of the triangle.

## 📎 Example:

```py
print(area_of_triangle(3, 5))  # 7.5
print(area_of_triangle(4, 2))  # 4.0
```

## 💡 Hint:

+ The `/` operator always returns a `float`, even if the result is a whole number.
