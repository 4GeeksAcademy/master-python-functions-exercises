# `000` Welcome to Master Python: Functions and Numbers

We are very excited to have you here! 🎉

In this LearnPack you will solve small numeric problems by writing functions. Almost every exercise asks you to **return** a value (not print it), so the tests can check your result.

## What will you practice?

- **Exercises:** `001-026`
- **Focus:** defining functions, parameters, `return` (including several values), arithmetic operators, integer division and modulo, the `math` module, rounding, conditionals and simple loops
- **Difficulty:** beginner

## How to work on each exercise

1. Read the instructions.
2. Write your solution in `app.py`.
3. Click **Run** to see what your code prints.
4. Click **Test** and iterate until every test passes.
