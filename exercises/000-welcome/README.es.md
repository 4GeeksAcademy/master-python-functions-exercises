# `000` Bienvenido a Master Python: Funciones y números

¡Nos entusiasma mucho tenerte aquí! 🎉

En este LearnPack vas a resolver pequeños problemas numéricos escribiendo funciones. Casi todos los ejercicios te piden **retornar** un valor (no imprimirlo), para que los tests puedan comprobar tu resultado.

## ¿Qué vas a practicar?

- **Ejercicios:** `001-026`
- **Enfoque:** definir funciones, parámetros, `return` (incluso de varios valores), operadores aritméticos, división entera y módulo, el módulo `math`, redondeo, condicionales y bucles simples
- **Dificultad:** principiante

## Cómo trabajar cada ejercicio

1. Lee las instrucciones.
2. Escribe tu solución en `app.py`.
3. Haz clic en **Run** para ver lo que imprime tu código.
4. Haz clic en **Test** y repite hasta que pasen todos los tests.
