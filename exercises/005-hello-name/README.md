# `005` Hello, Name!

## 📝 Instructions:

1. Complete the function `hello_name(name)`.

2. **Return** a greeting with this exact format: `Hello, <name>!`

## 📎 Example:

```py
print(hello_name("Harry"))  # Hello, Harry!
print(hello_name("Ana"))  # Hello, Ana!
```

The result must match character by character: a comma after `Hello`, one space, the name and an exclamation mark with no space before it.

## 💡 Hints:

+ You can join strings with `+`: `"Hello, " + name + "!"`.

+ Or use an f-string: `f"Hello, {name}!"`.
