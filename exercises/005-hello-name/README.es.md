# `005` ¡Hola, nombre!

## 📝 Instrucciones:

1. Completa la función `hello_name(name)`.

2. **Retorna** un saludo con este formato exacto: `Hello, <name>!`

## 📎 Ejemplo:

```py
print(hello_name("Harry"))  # Hello, Harry!
print(hello_name("Ana"))  # Hello, Ana!
```

El resultado debe coincidir carácter por carácter: una coma después de `Hello`, un espacio, el nombre y un signo de exclamación sin espacio antes.

## 💡 Pistas:

+ Puedes unir strings con `+`: `"Hello, " + name + "!"`.

+ O usar un f-string: `f"Hello, {name}!"`.
