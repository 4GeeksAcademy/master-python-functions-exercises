# `002` Sum of Three Numbers

A function receives values through its **parameters** and gives a result back with `return`.

## 📝 Instructions:

1. Complete the function `sum_of_three_numbers(a, b, c)`.

2. **Return** the sum of the three numbers.

## 📎 Example:

```py
print(sum_of_three_numbers(2, 3, 6))  # 11
print(sum_of_three_numbers(0, 3, 7))  # 10
```

## 💡 Hint:

+ `print()` only shows a value in the console; `return` sends it back to whoever called the function. The tests check what you **return**.
