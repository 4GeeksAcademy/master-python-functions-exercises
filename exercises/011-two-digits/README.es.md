# `011` Dos dígitos

## 📝 Instrucciones:

1. Completa la función `two_digits(number)`. Recibe un entero de dos dígitos.

2. **Retorna** dos valores: el dígito de las decenas (izquierda) y el de las unidades (derecha).

## 📎 Ejemplo:

```py
print(two_digits(79))  # (7, 9)
print(two_digits(30))  # (3, 0)
```

## 💡 Pista:

+ `number // 10` te da las decenas y `number % 10` te da las unidades.
