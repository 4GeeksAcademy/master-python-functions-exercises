# `011` Two Digits

## 📝 Instructions:

1. Complete the function `two_digits(number)`. It receives a two-digit integer.

2. **Return** two values: the tens digit (left) and the units digit (right).

## 📎 Example:

```py
print(two_digits(79))  # (7, 9)
print(two_digits(30))  # (3, 0)
```

## 💡 Hint:

+ `number // 10` gives you the tens and `number % 10` gives you the units.
