# `013` Last Two Digits

## 📝 Instructions:

1. Complete the function `last_two_digits(number)`. It receives an integer greater than `9`.

2. **Return** the number formed by its last two digits.

## 📎 Example:

```py
print(last_two_digits(1234))  # 34
print(last_two_digits(1205))  # 5
```
