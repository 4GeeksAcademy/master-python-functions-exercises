# `013` Últimos dos dígitos

## 📝 Instrucciones:

1. Completa la función `last_two_digits(number)`. Recibe un entero mayor que `9`.

2. **Retorna** el número formado por sus dos últimos dígitos.

## 📎 Ejemplo:

```py
print(last_two_digits(1234))  # 34
print(last_two_digits(1205))  # 5
```
