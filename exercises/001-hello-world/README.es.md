# `001` Hola mundo

En Python usamos `print()` para mostrar cualquier valor en la **consola**: un texto, un número o el contenido de una variable.

Hoy en día la consola se usa sobre todo para monitorear y depurar programas: te permite ver qué está haciendo tu código mientras se ejecuta.

## 📝 Instrucciones:

1. Usa `print()` para mostrar el texto `Hello World` en la consola.

## 📎 Ejemplo:

```py
print("How are you?")  # How are you?
```

## 💡 Pistas:

+ Los textos (strings) van entre comillas: `"Hello World"`.

+ Cuidado con las mayúsculas: los tests esperan exactamente `Hello World`.
