# `001` Hello World

In Python we use `print()` to show any value in the **console**: a text, a number or the content of a variable.

Today the console is mostly used to monitor and debug programs: it lets you see what your code is doing while it runs.

## 📝 Instructions:

1. Use `print()` to show the text `Hello World` in the console.

## 📎 Example:

```py
print("How are you?")  # How are you?
```

## 💡 Hints:

+ Text values (strings) go between quotes: `"Hello World"`.

+ Watch out for uppercase letters: the tests expect exactly `Hello World`.
