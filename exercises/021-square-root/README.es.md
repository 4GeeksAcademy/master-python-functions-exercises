# `021` Raíz cuadrada

## 📝 Instrucciones:

1. Completa la función `square_root(number)`.

2. **Retorna** la raíz cuadrada del número, redondeada a 2 decimales.

## 📎 Ejemplo:

```py
print(square_root(50))  # 7.07
print(square_root(16))  # 4.0
```

## 💡 Pistas:

+ El módulo `math` tiene la función `math.sqrt()`.

+ `round(value, 2)` redondea un número a 2 decimales.
