# `021` Square Root

## 📝 Instructions:

1. Complete the function `square_root(number)`.

2. **Return** the square root of the number, rounded to 2 decimals.

## 📎 Example:

```py
print(square_root(50))  # 7.07
print(square_root(16))  # 4.0
```

## 💡 Hints:

+ The `math` module has a `math.sqrt()` function.

+ `round(value, 2)` rounds a number to 2 decimals.
